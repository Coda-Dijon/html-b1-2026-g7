# Co-authored-by

Github vous propose **une adresse e-mail spéciale** basée sur le **nom d'utilisateur github**. Ca permet d’associer à coup sûr son compte github existant. Sans avoir à connaître son adresse e-mail.

Pour faire un commit à plusieurs auteurs.

Ajouter une ligne dans votre message de commit pour chaque co-auteur supplémentaire:

```
feat: mise en page responsive
Co-authored-by: name <githubusername@users.noreply.github.com>

```

Ex. si mon co-auteur est Marc Bouvier et a comme handle github `marc-bouvier`
```
feat: mise en page responsive
Co-authored-by: Marc Bouvier <marc-bouvier@users.noreply.github.com>

```
